Release Notes

Release Notes V2.0

El sitio no fue actualizado durante aproximadamente dos años. El motivo fue que el BCRA cambió la forma en que publicaba su informe estadístico, lo que dejó de funcionar el proceso de scraping que utilizábamos para obtener los datos. El sitio ahora utiliza la API oficial del BCRA. Este es un proyecto independiente y sin fines de lucro, y fue actualizado cuando finalmente hubo tiempo para hacerlo.

Fuentes

  • Los datos ahora se obtienen directamente desde la API oficial del BCRA, en lugar de scrapear la página de estadísticas del Banco Central.

Librería de Gráficos

  • Mejora funcional: Ahora es posible hacer clic en un hito para hacer zoom en ese período de tiempo (por ejemplo, una presidencia o un período de un ministro de economía).
  • Mejoras visuales: Numerosas mejoras visuales en toda la interfaz.

Reportes

La selección de reportes fue revisada y simplificada. Se incorporaron nuevos reportes y se eliminaron aquellos que ya no son relevantes.

Nuevos reportes:

  • M2
  • M2 en USD
  • M2 Dividido Reservas Internacionales y Cotización del Dólar
  • Operaciones de Pase BCRA
  • ICL
  • Rentabilidades — consolida en un único reporte las tres páginas de rentabilidad que existían anteriormente.

Reportes eliminados:

  • LEBAC — El BCRA dejó de utilizar este instrumento de política monetaria, por lo que el reporte ya no tiene relevancia.
  • LELIQ — El BCRA dejó de utilizar este instrumento de política monetaria, por lo que el reporte ya no tiene relevancia.
  • LELIQ En USD — El BCRA dejó de utilizar este instrumento de política monetaria, por lo que el reporte ya no tiene relevancia.
  • M2 Privado Variación Mensual — Reemplazado por los nuevos reportes de M2, que ofrecen una visión más completa del agregado monetario.
  • Inflación Interanual vs Base Interanual — Estos reportes superponían dos series en un mismo gráfico, lo cual resulta visualmente intuitivo pero metodológicamente incorrecto. Para analizar la relación entre estas variables lo apropiado es un análisis de correlación, no un gráfico de líneas compartido. Dado que no queremos presentar información de forma no metodológicamente correcta, decidimos eliminarlos.
  • Inflación Interanual vs Dólar Interanual — Ídem anterior.
  • Inflación Interanual vs Dólar Oficial Interanual — Ídem anterior.
  • Inflación Interanual vs Merval Interanual — Ídem anterior.
  • Rentabilidad Anual del Dólar vs Tasa de Interés por Depósitos — reemplazado por Rentabilidades.
  • Rentabilidad Anual del Dólar Oficial vs Tasa de Interés por Depósitos — reemplazado por Rentabilidades.
  • Rentabilidad Anual del Merval vs Tasa de Interés por Depósitos — reemplazado por Rentabilidades.
