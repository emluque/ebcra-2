  • Latest data: the date of the most recent value we have stored for the variable. If the source stops publishing new values, this date stays where it is, even if we keep checking it. When it is more than {{ stale_threshold_days }} days old, the variable is marked as "Stale data".
  • Last fetched: the last day we tried to get data from the source, whether or not the attempt succeeded or brought anything new.
  • Last ingestion: the last day new data was actually added, that is, the last time the "Latest data" date moved forward.

  • Último dato: la fecha del valor más reciente que tenemos guardado para la variable. Si la fuente deja de publicar valores nuevos, esta fecha no avanza, aunque la sigamos consultando. Cuando tiene más de {{ stale_threshold_days }} días de antigüedad, la variable se marca como "Datos desactualizados".
  • Última consulta: el último día en que intentamos obtener datos de la fuente, haya funcionado o no el intento y haya traído o no datos nuevos.
  • Última ingesta: el último día en que efectivamente se agregaron datos nuevos, es decir, la última vez que avanzó la fecha de "Último dato".

Para una explicación completa de las fuentes utilizadas en el sitio, vea Fuentes.
