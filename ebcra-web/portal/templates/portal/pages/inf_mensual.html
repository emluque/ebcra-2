{% if lang == 'en' %}Monthly Inflation (Official){% else %}Inflación Mensual (Oficial){% endif %}

{% if lang == 'en' %}Monthly change in Argentina's Consumer Price Index (CPI), sourced from the BCRA, which aggregates data from INDEC. Between November 2015 and January 2016, the BCRA uses the Buenos Aires City CPI. Between February and April 2016, it uses the San Luis CPI.{% else %}Variación mensual del Índice de Precios al Consumidor (IPC) de Argentina, obtenida del BCRA, que agrega datos del INDEC. Entre noviembre de 2015 y enero de 2016, el BCRA utiliza el IPC de la Ciudad de Buenos Aires. Entre febrero y abril de 2016, utiliza el IPC de San Luis.{% endif %}

{% if lang == 'en' %}Note: Official inflation data for 2007–2016 is not considered reliable. During that period INDEC was intervened and its reported figures are widely disputed. Read more: Note on inflation data.{% else %}Nota: Los datos oficiales de inflación del período 2007–2016 no son considerados confiables. El INDEC fue intervenido durante ese período y sus cifras son ampliamente cuestionadas. Lea más: Nota sobre los datos de inflación.{% endif %}
