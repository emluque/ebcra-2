{% if lang == 'en' %}Data published by the BCRA{% else %}Datos publicados por el BCRA{% endif %}

{% if lang == 'en' %}BCRA variable data is obtained daily via the official BCRA public API. This replaced the previous approach of scraping data directly from the BCRA website.{% else %}Los datos de variables del BCRA se obtienen diariamente a través de la API pública oficial del BCRA. Esto reemplazó el enfoque anterior de extraer los datos directamente del sitio web del BCRA.{% endif %}

{% if lang == 'en' %}It is important to note that the BCRA publishes its data with several days of delay (generally 5 to 10 days). In addition, certain data — specifically bank account information — is published with an even greater delay.{% else %}Es importante considerar que el BCRA publica sus datos con varios días de atraso (en general de 5 a 10 días). Además de esto, hay ciertos datos, específicamente la información de cuentas bancarias, que es publicada con un atraso aun mayor.{% endif %}

{% if lang == 'en' %}This is why the information on the site may appear delayed.{% else %}Es por estos motivos que la información aparece atrasada en el sitio.{% endif %}

{% if lang == 'en' %}Data Completion{% else %}Completamiento de Datos{% endif %}

{% if lang == 'en' %}Since the BCRA does not provide data for every day (e.g. weekends or holidays), to develop the charts on days without data, the value from the last preceding day with records is used. For example, if July 9 has no records due to a public holiday, but July 8 and July 10 do, the values from July 8 are used to fill in July 9.{% else %}Dado que el BCRA no proporciona datos para todos los días (por ejemplo fines de semana o feriados) para poder desarrollar los gráficos en los días que no hay datos se toma el valor del último día anterior del que existen registros. Por ejemplo, si el día 9 de Julio no hay registros por ser feriado, pero los hay para el 8 de Julio y para el 10 de Julio, se toman los valores del día 8 de Julio para completar los del 9 de Julio.{% endif %}

{% if lang == 'en' %}Own Elaboration{% else %}Elaboración Propia{% endif %}

{% if lang == 'en' %}Some series shown on the site are not published directly by any official source but are calculated by this site from primary data. These are labeled "Own Elaboration" in the per-page breakdown below. Typical operations include: dividing a monetary aggregate in ARS by an exchange rate to obtain a USD value, summing two monetary aggregates, dividing one series by another to express it as a ratio, and computing year-over-year percentage change using the formula ((current value / value one year prior) × 100) − 100.{% else %}Algunas series que se muestran en el sitio no son publicadas directamente por ninguna fuente oficial, sino que son calculadas por este sitio a partir de datos primarios. Estas se denominan "Elaboración Propia" en el detalle por página más abajo. Las operaciones típicas incluyen: dividir un agregado monetario en ARS por un tipo de cambio para obtener el valor en dólares, sumar dos agregados monetarios, dividir una serie por otra para expresarla como un ratio, y calcular la variación interanual mediante la fórmula ((valor actual / valor del año anterior) × 100) − 100.{% endif %}
