{% if lang == 'en' %}Notes on Old API (Deprecated){% else %}Notas sobre la API Antigua (Deprecada){% endif %}

{% if lang == 'en' %}

This website began as an independent project with a straightforward goal: to make the economic data published by the Central Bank of Argentina (BCRA) more accessible and easier to interpret. At the time, the BCRA published its key statistics on a page called Principales Variables, but the data was presented in a format that was difficult to navigate and offered no visual representation. To address this, the site was built to extract that data regularly, process it, and display it through a series of reports and interactive charts.

As the project grew, it became clear that the underlying data pipeline — the mechanism used internally to fetch and serve information to the charts — could be valuable to others beyond just the readers of this site. Developers, researchers, economists, and journalists might want to consume the same data programmatically without having to scrape the BCRA's website themselves. With that in mind, the decision was made to open up the internal API and make it publicly available, complete with documentation and a registration system to manage access.

Over the years, the API was used by a number of external projects and integrations. However, the landscape has since changed significantly. The Central Bank of Argentina has now launched its own official public API, providing direct and authoritative access to its data. Given this development, continuing to operate and support a third-party alternative no longer serves a meaningful purpose. Maintaining a parallel API introduces unnecessary complexity and could lead users toward a less authoritative data source when an official one is readily available.

For these reasons, this API has been formally deprecated and is no longer operational. We encourage all users and integrations that previously relied on this API to migrate to the official BCRA API, which can be found at the address below:

https://www.bcra.gob.ar/en/central-bank-api-catalog/

Este sitio nació como un proyecto independiente con un objetivo concreto: hacer que los datos económicos publicados por el Banco Central de la República Argentina (BCRA) fueran más accesibles y fáciles de interpretar. En ese entonces, el BCRA publicaba sus estadísticas principales en una página denominada Principales Variables, pero la información se presentaba en un formato difícil de navegar y sin ningún tipo de representación visual. Para resolver eso, se desarrolló este sitio con la intención de extraer esos datos de forma periódica, procesarlos y mostrarlos a través de una serie de reportes y gráficos interactivos.

A medida que el proyecto fue creciendo, se hizo evidente que el mecanismo interno utilizado para obtener y servir la información a los gráficos podía resultar valioso para otras personas más allá de los lectores del sitio. Desarrolladores, investigadores, economistas y periodistas podrían querer consumir esos mismos datos de forma programática, sin tener que hacer scraping del sitio del BCRA por su cuenta. Con ese propósito en mente, se tomó la decisión de abrir la API interna y ponerla a disposición del público en general, con su correspondiente documentación y un sistema de registro para gestionar el acceso.

Durante años, la API fue utilizada por varios proyectos e integraciones externas. Sin embargo, el contexto ha cambiado de manera significativa. El Banco Central de la República Argentina ha lanzado su propia API pública oficial, ofreciendo acceso directo y autorizado a sus datos. Ante este escenario, continuar operando y dando soporte a una alternativa de terceros ya no cumple ningún propósito relevante. Mantener una API paralela introduce complejidad innecesaria y podría llevar a los usuarios a recurrir a una fuente menos autorizada cuando existe una oficial disponible.

Por estos motivos, esta API ha sido formalmente deprecada y ya no se encuentra en funcionamiento. Recomendamos a todos los usuarios e integraciones que dependían de esta API que migren a la API oficial del BCRA, disponible en la siguiente dirección:

https://www.bcra.gob.ar/en/central-bank-api-catalog/
